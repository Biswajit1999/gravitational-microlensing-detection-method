# Image Sourcing — Gravitational Microlensing

Guidance for adding illustrative images to this repo. Two tracks: real
archival imagery first, AI-generation as a fallback. Every image needs
a caption naming the real mission/instrument depicted — AI-generated
images must say so explicitly and must never name the generating tool.

## Real sources to check first

- NASA Roman Space Telescope image/graphics library (public domain,
  includes microlensing-geometry diagrams) —
  <https://roman.gsfc.nasa.gov/multimedia.html>
- OGLE and MOA project outreach pages (check individual image
  licensing before use)

**hero:** search "Roman Space Telescope microlensing event diagram
NASA" on roman.gsfc.nasa.gov.

**instrument:** an official Roman Space Telescope illustration
(public domain, NASA).

## AI-generation fallback prompts

- **hero:** "Artist's concept of gravitational microlensing: a
  foreground star bending and brightening the light of a distant
  background star, Einstein ring effect, deep space"
- **3d:** "Close-up stylized render of spacetime curvature bending
  starlight around a foreground star with a small orbiting planet"
- **instrument:** "Photorealistic illustration of the Roman Space
  Telescope in space, sunshield deployed"

## Citation rule

- AI-generated: caption states "AI-generated illustration/concept —
  not a real photograph," names the real mission/instrument, never
  names the generating tool.
- Real archival photo: cite the actual mission/observatory directly —
  no AI-credit line needed.
